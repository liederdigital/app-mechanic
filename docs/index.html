Frequently Asked Questions

Why does App Mechanic open in my web browser instead of a native window? +
By serving its glassmorphic UI on http://localhost:8000 using Python's built-in http.server, App Mechanic avoids bundling a 200 MB Chromium/Electron runtime. You get silky-smooth animations and zero background RAM bloat, and when you click 🛑 Quit in the header, the background server shuts down completely.
Do I need Homebrew and mas installed? +
Yes — for accurate version comparisons, we strongly recommend having Homebrew and the Mac App Store CLI (brew install mas) installed. Even for apps you installed manually by dragging a .dmg to /Applications, App Mechanic cross-references their bundle names against the Homebrew Cask JSON catalog to let you know when a newer version is out!
Does App Mechanic send my installed app list anywhere? +
Never. All scanning happens 100% locally on your Mac. The app only makes read-only requests to public package catalogs (formulae.brew.sh, pypi.org, and GitHub Releases to check for App Mechanic self-updates) plus Gumroad's license verification endpoint when activating a Pro key.
What happens if I double-click App Mechanic while it's already running? +
App Mechanic has single-instance detection built in. If the server is already running on port 8000 and you closed your browser tab, double-clicking App Mechanic.app again simply re-opens http://localhost:8000 to your existing dashboard instantaneously.
Is App Mechanic safe to run on macOS Gatekeeper? +
Yes! App Mechanic is officially code-signed with a Developer ID by Lieder Digital, LLC and Notarized by Apple, so macOS Gatekeeper verifies its integrity out of the box without scary "unidentified developer" warnings.
How do I activate my Pro license key? +
Click any 🔒 Unlock Pro button in the dashboard table (or when prompted after your 3rd free scan), paste your Gumroad license key into the modal, and click Activate. Your license is saved locally in ~/Library/Application Support/AppMechanic/license.json.
